# ClaimFlow — Policy-Driven Expense Claim & Multi-Level Approval Engine

A Java + MySQL (JDBC) system that validates employee expense claims against
grade- and city-based company policy, routes them through the management
hierarchy according to amount, enforces department budgets safely, and keeps
a tamper-resistant audit trail.

> 🚧 **Status:** under construction — built step by step as a learning project
> after studying Java OOP and SQL (CDAC PGCP-AC). Each milestone is tagged
> (`step-01`, `step-02`, …) so the learning path is visible in the history.

## Tech stack
Java 17 (LTS) · MySQL 8.4 LTS (InnoDB) · JDBC (MySQL Connector/J) · Console UI
